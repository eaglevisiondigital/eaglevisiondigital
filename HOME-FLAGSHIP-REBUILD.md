# Eagle Vision Digital — Flagship Home Rebuild (State-of-the-Art Pass)

This is the strategic reset of the Home page. It is intentionally not a line-for-line duplicate of the prior prototype.

## Design objective
Build the flagship site as a national-caliber technology company headquartered on Florida's Emerald Coast.

## Major decisions
- One logo in the header; no duplicate giant logo in the hero.
- Hero prioritizes value proposition + approved device artwork.
- Industries rebuilt as semantic/clickable HTML cards using cropped exact approved icon artwork.
- Outcomes appear before services.
- Three major service graphics remain featured; portals, membership platforms and payments become clean supporting cards.
- New connected-ecosystem section explains Eagle Vision's differentiator: Website → App → Portal → Automation → Payments → Analytics.
- Solution Finder is now a functional 5-question interactive assessment with instant recommendation.
- Why Eagle Vision reduced from six equally heavy panels to three primary differentiators plus compact proof points.
- Process is a clean timeline using the approved process artwork.
- Founder copy is shortened; technology/business credibility is prioritized on Home.
- Local SEO is integrated without making the brand appear local-only.
